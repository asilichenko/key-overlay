# Key Overlay

Display pressed keys in the overlay: LCtrl, RCtrl, LShift, RShift.

<img width="362" src="https://github.com/user-attachments/assets/f30c945d-aa91-4cb1-994f-f6aeeae10f29" />

## Requirements

```
pip install -r requirements.txt
```

## Run

```
python -m key_overlay
```

## Build exe

```
python scripts/build.py
```
